# Introduction to Cyber Security

## 🧠 What is Cyber Security?
Cyber security means protecting computers, networks, and data from digital attacks. It's not just about stopping hacking, but also about securing and monitoring systems.

## 📌 Key Concepts
- **CIA Triad:** 
  - Confidentiality (Only authorized people can view it)
  - Integrity (Data is accurate and unaltered)
  - Availability (Data is available when needed)
- **Offensive Security vs Defensive Security:** 
  - Offensive = Red Team (Thinking like attackers)
  - Defensive = Blue Team (Defending systems)
- **Career Paths in Cyber:** Penetration Tester, SOC Analyst, Cloud Security, Malware Analyst.

## 🎯 Pentester Perspective
- To become a good pentester, you first need to understand what you are defending.
- In ethical hacking, permission is always required. Testing without permission is illegal.

# Offensive Security Intro

## 🧠 What is it?
Offensive security is the practice of breaking into systems, networks, and applications with legal permission to find vulnerabilities before real attackers do. It's also known as "Red Teaming" or "Ethical Hacking."

## 📌 Key Concepts
- **Ethical Hacking:** Hacking with permission to improve security.
- **Red Team:** Offensive security professionals who simulate attacks.
- **Vulnerability:** A weakness in a system that can be exploited.
- **Exploitation:** Taking advantage of a vulnerability.
- **Penetration Testing:** A simulated cyberattack against a system to check for exploitable vulnerabilities.

## 🎯 Pentester Perspective
- Offensive security is about thinking like an attacker to defend better.
- **Permission is key.** Without written authorization, hacking is illegal.
- This room gave a glimpse of how to hack a website legally in a safe environment.

## 🧪 Commands / Tools
- Gobuster (Directory busting)
- Basic web browser interactions (Inspecting a website's source code)

## 📌 Key Takeaway
"To stop a hacker, you need to think like one. But always stay on the ethical side."

# Defensive Security Intro

## 🧠 What is it?
Defensive security is the practice of protecting systems, networks, and data from cyber threats. It focuses on detecting, preventing, and responding to attacks. It's also known as "Blue Teaming."

## 📌 Key Concepts
- **Threat Intelligence:** Gathering information about current and potential threats.
- **SOC (Security Operations Center):** A team that monitors and responds to security incidents 24/7.
- **DFIR (Digital Forensics and Incident Response):** Investigating breaches and responding to them.
- **Malware Analysis:** Studying malicious software to understand how it works and how to stop it.
- **SIEM (Security Information and Event Management):** Tools that collect and analyze logs to detect suspicious activity.

## 🎯 Pentester Perspective
- Understanding defensive security helps pentesters know what defenders are looking for.
- Pentesters must learn to bypass SIEM, Firewalls, and EDR (Endpoint Detection and Response) tools.
- Logs are a defender's best friend, and an attacker's worst enemy.

## 🧪 Commands / Tools
- SIEM (e.g., Splunk, ELK Stack)
- Firewalls & IDS/IPS (Intrusion Detection/Prevention Systems)

## 📌 Key Takeaway
"Defensive security is not just about building walls; it's about monitoring, detecting, and responding to threats in real-time."

# Careers in Cyber

## 🧠 What is it?
Cyber security is a vast field with many different career paths. This room explored the various job roles available in the industry.

## 📌 Key Concepts / Career Paths
- **Penetration Tester:** Tests systems for vulnerabilities by simulating attacks.
- **SOC Analyst:** Monitors networks and systems for security breaches.
- **Incident Responder:** Handles security breaches and investigates how they happened.
- **Malware Analyst:** Analyzes malicious software to understand its behavior.
- **Cloud Security Engineer:** Secures cloud infrastructure (AWS, Azure, GCP).
- **GRC (Governance, Risk, and Compliance):** Ensures the organization follows security policies and regulations.

## 🎯 Pentester Perspective
- You don't have to choose one path immediately. Explore different areas.
- Offensive (Red Team) and Defensive (Blue Team) roles often overlap.
- Cloud security and Penetration testing are currently in high demand.

## 📌 Key Takeaway
"Cyber security is not just one job; it's an ecosystem of roles. Find the one that matches your passion."
